# Asciiland

A small playground of living ASCII-art trees. Hold, drag and press to play with them.

## Run it
1. Install Node.js (once).
2. In this folder run `npm install` (once).
3. Run `npm run dev` and open the address it prints (usually http://localhost:5173). The page refreshes when you save a file.

Other commands: `npm run build` makes the final site in `dist/`, `npm run preview` shows that build.

## Deploy on Vercel
1. Push this repo to GitHub.
2. On vercel.com choose **Add New → Project** and import the repo.
3. Leave every setting as it is (Vercel detects Vite) and click **Deploy**.

After that, every push to `main` updates the live site, and other branches get preview links.

See `CLAUDE.md` for the project rules and `BUILDLOG.md` for progress.
